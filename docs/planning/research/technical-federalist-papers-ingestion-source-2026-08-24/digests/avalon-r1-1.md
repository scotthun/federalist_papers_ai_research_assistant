## Digest: Avalon Project
### Claims
- Avalon Project is a digital library of law/history/diplomacy documents maintained by Yale Law School's Lillian Goldman Law Library and is listed as an official Yale University Library digital collection — source: https://web.library.yale.edu/digital-collections/avalon-project (Yale University Library), pub_date: undated, accessed: 2026-08-24, confidence: high, class: 1
- The Library of Congress's own Federalist Papers research guide names and links the Avalon Project as an external resource for primary-source Federalist text — source: https://guides.loc.gov/federalist-papers/external-websites (Library of Congress), pub_date: undated, accessed: 2026-08-24, confidence: high, class: 1
- Avalon Project launched in 1996/1997, one of the older digital text projects on the internet — source: https://en.wikipedia.org/wiki/Avalon_Project, accessed: 2026-08-24, confidence: medium, class: 1
- Predecessor Avalon URL (www.yale.edu/lawweb/avalon/) has a Wayback capture as early as 1997-08-09, corroborating mid-1990s launch — source: web.archive.org CDX API, accessed: 2026-08-24, confidence: high, class: 1/4
- Sample pages (No. 1: avalon.law.yale.edu/18th_century/fed01.asp; No. 85: .../fed85.asp) are plain HTML, no login wall/paywall/CAPTCHA, full text + author byline + footnotes + prev/next nav, identical template — source: direct fetch, accessed: 2026-08-24, confidence: high, class: 2
- URL pattern: `https://avalon.law.yale.edu/18th_century/fed{NN}.asp`, zero-padded 01-85, verified on Nos. 1, 10, 85 — source: direct fetch + search results, accessed: 2026-08-24, confidence: high, class: 2
- Index page (avalon.law.yale.edu/subject_menus/fed.asp) lists all 85 papers as plain numbered hyperlinks, same fedNN.asp pattern — source: direct fetch, accessed: 2026-08-24, confidence: high, class: 2/3
- Both endpoints (No. 1, No. 85) spot-checked, full essay text returned — not a partial/abridged subset — source: direct fetch, accessed: 2026-08-24, confidence: high, class: 3
- Current URL scheme stable since at least 2008: Wayback CDX shows earliest capture of fed01.asp on 2008-10-23 (HTTP 200), 499 total captures through 2026-08-19, all resolving at the same path — source: web.archive.org CDX API, accessed: 2026-08-24, confidence: high, class: 4
- URL scheme DID change once: pre-migration path www.yale.edu/lawweb/avalon/federal/fed01.htm (live ~2003) now 404s (2024/2025 captures) — a link saved pre-2008 would break, but anything since ~2008-2009 under /18th_century/fedNN.asp still resolves unchanged — source: web.archive.org CDX API, accessed: 2026-08-24, confidence: high, class: 4
