- (source) Round 1: 3 parallel researchers (production RAG practice, academic abstention literature, threshold calibration). Digests written to digests/production-practice-r1-1.md, digests/academic-lit-r1-1.md, digests/threshold-calibration-r1-1.md
- (claim) ref=[1] status=verified class=patterns pub=2026-08 — No production RAG system found using a three-way similarity-threshold-gated answer/clarify/refuse split; the real precedent for that pattern is NLU/intent-classification (Rasa Two-Stage Fallback, Amazon Lex confidence bands), not RAG
- (claim) ref=[2] status=verified class=patterns pub=2024-01 — CRAG (the closest true RAG analog to a 3-tier design) gates on a separately trained classifier's confidence score, not raw embedding similarity
- (claim) ref=[3] status=verified class=patterns pub=2025-05 — Google Research found that adding retrieved-but-insufficient context can INCREASE hallucination rather than trigger abstention (Gemma: 10.2%% hallucination with no context vs 66.1%% with insufficient context) — undercuts the assumption that high similarity implies safe-to-answer
- (claim) ref=[4] status=verified class=versions_compat pub=2026-08 — No universal similarity threshold exists across embedding models/datasets; every source recommends empirical calibration against an eval set, with 0.7-0.8 appearing only as an illustrative (not validated) starting point
- (event) Research complete: three-tier design is not a RAG-native pattern (real RAG systems use binary threshold or, for real 3-tier gating like CRAG, a trained classifier) but is a legitimate borrow from NLU confidence-banding. Key risk surfaced: pure similarity is a weak abstention signal per multiple 2025 papers. Recommendation forthcoming: keep 3-tier design for portfolio scope, calibrate thresholds empirically via the project's own retrieval eval set, and treat existing citation-verification safeguard as load-bearing (not redundant) given similarity's known unreliability.
