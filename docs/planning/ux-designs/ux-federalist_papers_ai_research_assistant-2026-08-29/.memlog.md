- (event) workspace created; Create mode; topic: chatbot-style conversational UI (floating icon, popup, streaming, in-chat navigation to papers/sections) for an existing app whose established ui-design.md explicitly says 'not a generic ChatGPT-clone look'
- (decision) Ask-the-Archive chat becomes a floating launcher icon, bottom-right corner (pattern: bank-site chat widgets like Chase/Capital One), not an embedded input on the main page
- (decision) Answer text streams in (token/word-by-word) rather than appearing all at once
- (decision) Default panel size: small corner popup window, docked bottom-right, page stays visible behind it (like a standard chat widget)
- (assumption) Future full-screen/takeover chat view is a maybe — deferred as out of scope for now, flagged as possibly too complex
- (decision) Clicking a citation inside the chat navigates to the Paper Reader and scrolls to/highlights the cited paragraph or line, consistent with existing citation-navigation behavior
- (decision) Chat widget is global and floats on top; the underlying page (Browse Papers, Paper Reader, etc.) is unaffected and stays exactly as it was
- (decision) Chat message history persists across page navigation (session-level state, not reset per-page), similar to RoboChat/Confluence pattern
- (decision) When user is on a specific Paper Reader page, that paper is offered as default context to the chat (RoboChat/Confluence-style page-aware context), rather than always being a blank general-archive query
- (decision) Page-aware context is shown visibly as a removable chip/pill in the chat (e.g. '📄 Federalist No. 10'), not applied silently — keeps scoping transparent and lets the user drop back to whole-archive search
- (decision) Launcher icon: a feather quill pen (period-appropriate — quills were the actual writing tool of the Federalist Papers era), not a generic chat-bubble icon
- (assumption) Open tension: replacing the homepage's inline 'Ask the Archive' box with only a floating quill icon risks hurting discoverability — first-time visitors may not realize they can ask questions at all. Not yet resolved; user is weighing whether a full-takeover chat view solves this better than a small popup.
- (decision) Discoverability resolved: floating quill replaces the inline 'Ask the Archive' box. First-time visitors get an animated nudge — the quill icon pulses once and a tooltip auto-opens ('Ask me about the Federalist Papers →'), then settles to icon-only. No full-takeover chat view, no persistent homepage callout.
- (decision) Visual direction chosen: 'Parchment & Manuscript' (aged-paper texture, warm serif type, sealing-wax red accents, sepia/gold palette) from .working/direction-parchment-manuscript.html — leans into the 1787 history angle, applies to the quill widget and by extension the app's overall visual identity
- (decision) Responsive behavior: on desktop the quill opens the small corner popup as decided; on mobile/small screens it expands to a full-screen chat view instead (standard chat-widget convention — Intercom/Drift/Zendesk-style — since a fixed-width popup doesn't fit alongside a usable page at phone widths)
- (assumption) Citation click inside the quill panel collapses the panel back to the launcher icon while navigating the page to the Paper Reader (conversation history preserved); not explicitly decided in discovery, made during Finalize doc-authoring — confirm before ship.
- (assumption) Desktop/mobile quill breakpoint assumed to reuse apps/web's existing responsive breakpoint token (~768px) rather than inventing a new value; exact behavior on orientation-change mid-conversation across the breakpoint is unresolved — confirm before ship.
